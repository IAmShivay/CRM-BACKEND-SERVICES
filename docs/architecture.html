Service-to-service

Internal routes  x-internal-key

Services call each other over plain HTTP using the k8s/Compose service name (SERVICE_URLS in shared-types) and the shared INTERNAL_API_KEY. These paths are blocked at the gateway: /api/whatsapp/internal/send, /api/ai/internal/auto-reply, /api/deals/internal/from-lead.

Frontend-only keys (NEXT_PUBLIC_*, API_GATEWAY_URL) are documented in the CRM-SASS docs; they are not read by any service here.
